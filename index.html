🧩 New: Lobby Overlay extension
Bring these lobby cards straight into openfront.io's own lobby picker, no more tab-switching to join a game.
  1. Install a userscript manager like Tampermonkey (Chrome, Edge, Firefox, Safari).
  2. On Chrome or Edge, open chrome://extensions, click "Details" under Tampermonkey, and turn on "Allow User Scripts".
  3. Click here to install the overlay script Tampermonkey will pop up an install prompt automatically.
  4. Click "Install" in that Tampermonkey tab.
  5. Open openfront.io and the lobby picker is replaced automatically.
